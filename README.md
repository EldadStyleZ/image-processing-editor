### Prerequisites
- Python 3.9+

### Quick Start
```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/image-processing-editor.git
cd image-processing-editor

# Install dependencies
pip install -r requirements.txt

# Run the application
python image_editor.py sample_image.png
```
